基于无人机图像的输电线路异物检测数据集![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/aa923a974881422e92ad4a11a4e2fe32.png)

面向输电线路异物检测的无人机视角图像数据集，聚焦输电线及周边区域常见悬挂、飘挂和侵入类异物，可用于电力巡检中的异物识别与风险预警研究。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/7de0bd7d67ab4606a2d0d2f5f93afc46.png)

任务类型：目标检测。该数据集主要用于输电线路异物目标的定位与识别。
数据规模：共包含 1495 张标注图像。官方实验中按 8:2 划分为训练集和测试集，其中训练集 1196 张，测试集 299 张。
图像类型：无人机视角图像，场景围绕输电线路巡检环境构建，具有较强的工程应用背景。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/5fab25418ad542aaa5e62838f102b41e.png)

类别设置：包含 6 类典型异物，分别为鸟巢、风筝、气球、火情、人员和猴子。
标注形式：提供目标边界框标注，适合用于主流目标检测模型训练与评测。
标注格式：标注采用 txt 格式，适用于YOLO系列。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/835d8e3232884eb4869f6d61f8a46a9a.png)

数据特点：覆盖多种地理背景和异物类型，兼顾典型输电线路巡检中常见的悬挂类、漂浮类和入侵类目标，场景多样性较好。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/bc345f16fa0c4bfda8a567de48ffe985.png)

数据难点：异物目标普遍尺寸较小，部分目标与背景对比度低，且不同类别在外观、尺度和出现频率上存在明显差异，容易受到复杂背景干扰。
适用方向：适用于输电线路异物检测、无人机巡检视觉分析、电力安全预警以及小目标检测相关研究。
